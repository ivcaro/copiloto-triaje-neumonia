# Dependencias de Python del proyecto, con su versión exacta: las mismas con las que pasan
# las pruebas en la imagen Linux de pruebas. Es la unión de `pyproject.toml` (el paquete
# `copiloto_triaje`: servidor, motor y entrenamiento) y de `app/requirements.txt` (la app de
# demostración), más las herramientas de las pruebas.
#
#     python -m venv .venv
#     pip install -r requirements.txt
#     python -m pytest
#
# El código del curso (`python -m src.evaluate`, `python -m src.train`...) funciona así, sin
# más. Para instalar además el paquete `copiloto_triaje` (lo que hacen las imágenes de Docker):
#
#     pip install --no-deps .
#
# La app de demostración y el servidor tienen su propia receta (`app/requirements.txt`,
# `servidor/Dockerfile`), que no cambia.
