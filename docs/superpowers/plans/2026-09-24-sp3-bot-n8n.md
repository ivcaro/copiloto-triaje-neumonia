# SP3 — Bot de Telegram en n8n: plan de implementación

> **Para trabajadores agénticos:** SUB-SKILL REQUERIDA: usa
> superpowers:subagent-driven-development (recomendado) o
> superpowers:executing-plans para ejecutar este plan tarea a tarea. Los pasos
> usan casillas (`- [ ]`) para el seguimiento.

**Objetivo:** dos bots de Telegram orquestados en n8n que recogen el
cuestionario de un paciente y la exploración más la radiografía de un
profesional, y devuelven lo que dice el copiloto ya desplegado.

**Arquitectura:** toda la lógica vive en tres workflows de n8n (enfoque A del
spec). El estado conversacional y los datos viven en una PostgreSQL propia
añadida al compose existente. El copiloto se consume por JSON-RPC contra
`/mcp` con un nodo HTTP Request, sin AI Agent. Las pruebas son de integración:
pytest fabrica `update`s de Telegram, los envía al webhook del workflow y
comprueba la base de datos.

**Pila:** n8n 2.35.4, PostgreSQL 16, Python 3.12 con pytest para las pruebas,
Docker Compose v2. Intérprete: `C:/venv-copiloto/Scripts/python.exe`.

**Spec:** `docs/superpowers/specs/2026-09-24-sp3-bot-n8n-design.md` — léelo
entero antes de la primera tarea. El plan argumenta desde él; en cualquier
contradicción, manda el spec.

## Restricciones globales

Copiadas literalmente del spec. **Las requisitos de cada tarea las incluyen.**

1. **No se modifica ningún workflow existente** del cliente. Los nuestros son
   nuevos y llevan el prefijo `🩺 Copiloto Triaje:`, los tres.
2. **No se reutiliza ninguna credencial de Telegram existente.** Los bots son
   nuevos de BotFather.
3. **No se crea ni se borra** `[retirado]_[retirado]_network`, ni se tocan sus otros
   contenedores.
4. **No se toca `copiloto-mcp`.** Si hiciera falta algo del servidor, se para y
   se decide.
5. `copiloto-bd` **no publica puertos**, y su contraseña no es la de ninguna
   otra base de datos de la máquina.
6. **No se cambia la configuración global de n8n**, solo la de nuestros
   workflows.
7. **Ninguna rama de error emite una cifra de probabilidad.**
8. El umbral operativo es `0.4258`. La banda contradictoria es
   `cruda ∈ [0,4258 ; 0,5786]`. La RV está acotada a `[0,0163 ; 77,32]`.
9. Los secretos **nunca** van al repositorio.

"""Lo que el bot de SP3 espera de copiloto-mcp.

Estas pruebas no comprueban el modelo: comprueban el CONTRATO. Si SP4 cambia
la forma de la respuesta, falla aqui en vez de romperse el bot en produccion.

import json
import os
import pathlib
import urllib.error
import urllib.request

import pytest

def _llamar(b64: str) -> dict:
    cuerpo = json.dumps({
        "jsonrpc": "2.0", "id": 1, "method": "tools/call",
        "params": {"name": "clasificar_radiografia",
                   "arguments": {"dicom_base64": b64}}}).encode()
    pet = urllib.request.Request(
        f"{BASE}/mcp", data=cuerpo,
        headers={"Content-Type": "application/json",
                 "Accept": "application/json, text/event-stream"})
    texto = urllib.request.urlopen(pet, timeout=30).read().decode()
    for linea in texto.splitlines():
        if linea.startswith("data: "):
            return json.loads(linea[6:])
    pytest.fail(f"la respuesta no traia ninguna linea 'data: ': {texto[:200]}")

def test_un_tools_call_suelto_basta_sin_saludo_initialize(dicom_adulto):
    """El servidor es stateless_http: n8n puede hacer UN solo HTTP Request.

    Si esto dejara de ser cierto, el flujo necesitaria mantener sesion MCP y
    el diseno entero de §10.1 se cae.
    """

def test_la_respuesta_trae_structuredContent_con_las_claves_del_spec(dicom_adulto):
    sc = _llamar(base64.b64encode(dicom_adulto).decode())["result"]["structuredContent"]
    assert set(sc) >= {
        "probabilidad_cruda", "probabilidad_calibrada", "razon_de_verosimilitud",
        "umbral", "clasificacion", "edad_paciente", "modelo", "auc_validacion",
        "milisegundos"}


def test_el_base64_envuelto_da_el_mismo_resultado_que_el_plano(dicom_adulto):
    """n8n puede envolver a 76 columnas; el servidor quita los saltos.

    Se comprueban LF y CRLF: CRLF es el salto del MIME canonico y escapado
    dentro del JSON cuesta el doble, que es por donde se colo un fallo en SP2.
    """
    plano = base64.b64encode(dicom_adulto).decode()
    esperado = _llamar(plano)["result"]["structuredContent"]
    for salto in ("\n", "\r\n"):
        envuelto = salto.join(plano[i:i + 76] for i in range(0, len(plano), 76))
        assert _llamar(envuelto)["result"]["structuredContent"] == esperado


def test_el_codigo_de_error_es_el_SEGUNDO_campo_del_texto(dicom_menor):
    """El SDK antepone su propio prefijo. Partir por el primer ':' devuelve
    'Error executing tool clasificar_radiografia', no el codigo.
    """
    r = _llamar(base64.b64encode(dicom_menor).decode())["result"]
    assert r["isError"] is True
    texto = r["content"][0]["text"]
    assert "fuera_de_alcance" in texto
    assert texto.split(":")[0].strip() != "fuera_de_alcance"


def test_el_rechazo_por_edad_no_trae_ninguna_cifra_de_probabilidad(dicom_menor):
    """Restriccion global 7. Si un numero se colara junto al rechazo, alguien
    lo usaria."""
    r = _llamar(base64.b64encode(dicom_menor).decode())["result"]
    assert r.get("structuredContent") in (None, {})
    texto = r["content"][0]["text"]

def test_el_base64_invalido_se_rechaza_y_no_se_ignora_en_silencio():
    r = _llamar("no-es-base64-*!")["result"]
    assert r["isError"] is True
    assert "base64_invalido" in r["content"][0]["text"]


def test_por_encima_del_limite_del_transporte_llega_un_413_y_no_un_SSE():
    """Hay DOS limites y no son el mismo (§10.4). Por encima de ~5,3 MiB el
    transporte corta ANTES del tool: la respuesta no es SSE, y buscar 'data: '
    en ella reventaria.
    """
    enorme = base64.b64encode(b"\x00" * (6 * 1024 * 1024)).decode()
    cuerpo = json.dumps({
        "jsonrpc": "2.0", "id": 1, "method": "tools/call",
        "params": {"name": "clasificar_radiografia",
                   "arguments": {"dicom_base64": enorme}}}).encode()
    pet = urllib.request.Request(
        f"{BASE}/mcp", data=cuerpo,
        headers={"Content-Type": "application/json",
                 "Accept": "application/json, text/event-stream"})
    with pytest.raises(urllib.error.HTTPError) as exc:
        urllib.request.urlopen(pet, timeout=30)
    assert exc.value.code == 413


def test_la_razon_de_verosimilitud_viene_acotada(dicom_adulto):
    """La cota es lo que impide que una sola imagen anule la clinica en SP4."""
    sc = _llamar(base64.b64encode(dicom_adulto).decode())["result"]["structuredContent"]
    assert 0.0163 <= sc["razon_de_verosimilitud"] <= 77.33

def test_el_codigo_tiene_seis_caracteres_del_alfabeto_sin_ambiguos(conexion):
    """Se dicta en voz alta en una consulta: ni 0/O ni 1/I/L."""
    permitidos = set("ABCDEFGHJKMNPQRSTUVWXYZ23456789")
    for _ in range(200):
        codigo = conexion.execute("SELECT generar_codigo()").fetchone()[0]
        assert len(codigo) == 6
        assert set(codigo) <= permitidos, codigo


def test_el_codigo_no_usa_un_alfabeto_sesgado(conexion):
    """Con muestreo por modulo simple, los 8 primeros caracteres saldrian ~29%
    mas que el resto. Con 6000 tiradas ese sesgo es visible."""
    from collections import Counter
    cuenta = Counter()
    for _ in range(1000):
        cuenta.update(conexion.execute("SELECT generar_codigo()").fetchone()[0])
    frecuencias = sorted(cuenta.values())
    assert frecuencias[-1] / frecuencias[0] < 1.5, dict(cuenta)

-- El codigo seudonimo: 6 caracteres de un alfabeto de 31, sin 0/O ni 1/I/L
-- porque se dicta en voz alta en una consulta.
--
-- El bucle interior es muestreo por RECHAZO y no un modulo a secas: 256 no es
-- multiplo de 31, asi que `byte % 31` haria salir los 8 primeros caracteres un
-- 29% mas que el resto. Descartando los bytes >= 248 (31*8) el reparto queda
-- uniforme. No es una frontera de seguridad, pero un alfabeto sesgado en algo
-- que se usa como identificador es deuda gratuita.
CREATE OR REPLACE FUNCTION generar_codigo() RETURNS text AS $$
DECLARE
  alfabeto constant text := 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
  resultado text := '';
  b integer;
BEGIN
  FOR _i IN 1..6 LOOP
    LOOP
      b := get_byte(gen_random_bytes(1), 0);
      EXIT WHEN b < 248;
    END LOOP;
    resultado := resultado || substr(alfabeto, 1 + (b % 31), 1);
  END LOOP;
  RETURN resultado;
END;
$$ LANGUAGE plpgsql VOLATILE;

"""Elige los ~60 casos del conjunto de prueba que cubren cada rama del bot.

Nivel 2 del §13.1 del spec. Telegram limita a ~1 mensaje por segundo y chat,
asi que reproducir las 3 811 conversaciones llevaria horas: se eligen unos

import sys

import pandas as pd
import torch
from torch.utils.data import DataLoader

sys.path.insert(0, str(REPO / "src"))

from copiloto_triaje.datos.dataset import DatasetRadiografias  # noqa: E402
from copiloto_triaje.modelo.arquitectura import construir_modelo  # noqa: E402

CRUDO = RAIZ / "crudo" / "stage_2_train_images"

def _puntuaciones() -> pd.DataFrame:
    """Las puntuaciones crudas del conjunto de prueba, cacheadas.

    Inferir sobre 3 811 imagenes tarda minutos; esto se llama desde pruebas.
    """
    if CACHE.is_file():
        return pd.read_csv(CACHE)
    df = pd.read_csv(RAIZ / "manifiestos" / "test.csv")
    cargador = DataLoader(
        DatasetRadiografias(df, RAIZ / "png", 320, entrenamiento=False),
        batch_size=32, num_workers=4)
    modelo = construir_modelo("efficientnet_b0", congelar_backbone=False,
                              preentrenado=False)
    modelo.load_state_dict(torch.load(
        REPO / "servidor" / "pesos_modelo_cpu.pt",
        map_location="cpu", weights_only=True))
    modelo.eval()
    crudas = []
    with torch.no_grad():
        for x, _ in cargador:
            crudas.append(torch.sigmoid(modelo(x).view(-1)).numpy())
    df["cruda"] = np.concatenate(crudas)
    df.to_csv(CACHE, index=False)
    return df

    df = _puntuaciones()
    meta = pd.read_csv(REPO / "docs" / "eda" / "metadatos_eda.csv")

    df["edad"] = df.patientId.map(edades)

        # Los menores y las edades imposibles NO estan en test.csv: se filtraron

        "edad_imposible":       None,
    }
    fuera = meta[(meta.edad_num < 18) | (meta.edad_num > 100)]
    perfiles["menor_edad"] = fuera[fuera.edad_num < 18].assign(cruda=float("nan"),
                                                              etiqueta=-1)
    perfiles["edad_imposible"] = fuera[fuera.edad_num > 100].assign(
        cruda=float("nan"), etiqueta=-1)

    salida = {}
    for nombre, sub in perfiles.items():
        sub = sub.sort_values("patientId").head(n_por_perfil)
        salida[nombre] = [
            {"patientId": f.patientId,
             "ruta_dcm": str(CRUDO / f"{f.patientId}.dcm"),
             "cruda": float(f.cruda),
             "etiqueta": int(f.etiqueta),
             "edad": int(f.edad_num if "edad_num" in sub.columns else f.edad)}
            for f in sub.itertuples()]
    return salida


if __name__ == "__main__":
